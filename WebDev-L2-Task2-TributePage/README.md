# Mahatma Gandhi Tribute Page

## Project Overview

This project is a responsive tribute webpage dedicated to **Mahatma Gandhi**, one of the most influential leaders of India's freedom movement.

The webpage presents information about his life, achievements, values, important events, inspirational quotes, and interesting facts in a clean and user-friendly design.

## Features

* Attractive header section

* About Gandhi section
* Major achievements displayed using cards
* Important values and principles
* Historical timeline
* Inspirational quotes
* Interesting facts
* Responsive design for mobile and desktop screens

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and the image file are in the correct location.
4. Open `index.html` in any modern web browser.
5. The Tribute Page will be displayed.

## Responsive Design

The webpage is designed to work on different screen sizes. CSS media queries are used to adjust the layout, image size, heading size, and content for smaller screens.
