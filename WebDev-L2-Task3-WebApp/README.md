# To-Do List Web App

## Project Overview

This project is a simple and interactive **To-Do List Web Application** designed to help users manage their daily tasks efficiently.

Users can add new tasks, mark tasks as completed, edit existing tasks, and delete tasks. The application separates tasks into **Pending Tasks** and **Completed Tasks** for better organization.

## How to Run the Project

1. Download or clone the repository.
2. Open the `WebDev-L2-Task3-WebApp` folder.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in a modern web browser.
5. The To-Do List Web App will open and you can start managing your tasks.

## How It Works

### Add Task

Enter a task in the input field and click the **Add** button. The task will appear under Pending Tasks.

### Complete Task

Click the **Yes** button to mark a pending task as completed. The task will move to the Completed Tasks section.

### Edit Task

Click the **Edit** button to modify an existing task.

### Delete Task

Click the **Delete** button to remove a task from the list.
